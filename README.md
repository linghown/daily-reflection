# 📓 每日反思记录

记录每天做对、做错的事，持续改进自己的能力、情商和处理问题的方式。

## 📂 目录结构

```
daily-reflection/
├── README.md          # 说明文件
├── 2026-07-25.md      # 2026年7月25日
└── ...
```

## 📋 记录模板

每天包含以下板块：
- ✅ **做对的事** — 记录当天的正确决策和行动
- ❌ **做错的事 / 待改进** — 记录失误和教训
- 🎯 **今日改进计划** — 具体的改进行动
- 📝 **备注** — 补充说明

## 🔗 GitHub 同步

待 GitHub 授权恢复后，可通过以下命令同步：

```bash
cd daily-reflection
git init
git add .
git commit -m "初始化每日反思记录"
git remote add origin https://github.com/<你的用户名>/daily-reflection.git
git push -u origin main
```
